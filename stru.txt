# ROUTER CLEANUP

The project currently has a file such as:

Do not keep a script whose purpose is to modify the router source.

Create or use a proper router aggregator.

Example:

app/api/router.py

from fastapi import APIRouter

from app.api.resume import router as resume_router
from app.api.skill_gap import router as skill_gap_router
from app.api.roadmap import router as roadmap_router
from app.api.mentor import router as mentor_router
from app.api.study import router as study_router

api_router.include_router(resume_router, prefix="/resume", tags=["Resume"])
api_router.include_router(skill_gap_router, prefix="/skill-gap", tags=["Skill Gap"])
api_router.include_router(roadmap_router, prefix="/roadmap", tags=["Roadmap"])
api_router.include_router(mentor_router, prefix="/mentor", tags=["AI Mentor"])
api_router.include_router(study_router, prefix="/study", tags=["Study"])

Then keep main.py minimal.

Example:

from fastapi import FastAPI
from app.api.router import api_router

app = FastAPI(title="CareerOS AI Service")

app.include_router(api_router, prefix="/api")

Adapt prefixes to the existing API.

DO NOT accidentally change existing endpoint URLs.
